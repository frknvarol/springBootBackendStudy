# Backend Engineering Case Study


In this case study I have tried my best to reach the desired goals.

I have tried to implement dependency injection and loose coupling as much as possible.

I arranged the files in their own folders respectively (repository, service etc.)

I believe that the method and variable names speak for themselves and are clear so i refrained from adding too much comments.

Due to my finals and capstone project I wasn't able to commit the whole of my time to this case study so i could only
make unit tests for the controller layer.

My first consideration for the leaderboard table was to use a noSQL like mongodb but due to the time constraints 
I mentioned earlier i had to go along with indexing instead.

I have also added the json file for the postman collection.
